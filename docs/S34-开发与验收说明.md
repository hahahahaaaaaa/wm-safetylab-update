## 已实现的功能点

| 卡号 | 注册 ID | 参数 | 行为与边界 |
|---|---|---|---|
| #10 | b-score-misspec | mode=amplitude_bias/scale；c≥0；scale>0 | 分数加 c×std(scores)×mean(abs(actions))，或乘正比例；只修改 scores |
| #11 | b-constrained-rerank | v_max≥0 或 null | scores−(ptp(scores)+1)×(违规指示+超出量)；可行候选优先；全违规告警但不接管 |
| #8 | b-prediction-noise | c≥0；source=prior/value/both；stats/std | 仅 rollout 注入 c×各维 std×sqrt(h+1) 的高斯噪声；chosen_next 不改 |
| #9 | b-residual-monitor | scale>0；threshold≥0 | 同一转换的预测/实际编码 L2 残差；报告原始及归一化值；阈值比较用原始值 |
| #1 向量依赖 | a-obs-noise-vector | c≥0；start/end；stats/std | 指定步区间各维高斯噪声；日志明确实际注入，默认配置适用于 Toy |

共用 `b_residual.py` 可供 S6 使用；`b_numeric.py` 提供输入检查与统计加载。#1 最小模块也依赖此数值工具，交给 A 时需保留该依赖，避免另建重复注册 ID。

所有随机数来自 ctx.rng，跨回合状态在 reset 清理；不原地改输入。S3/S4 保持浮点 dtype 与形状，非法维度、非有限值和溢出明确报错。#9 不调用 alarm，不改动作，S5 修改动作或接管的步单独统计为 prediction_action_mismatch。
